# spacesim
A dumb little simulation of gravitational forces between objects in space

# Building
You have to install [raylib](https://github.com/raysan5/raylib) to compile this program <br>
To compile, run
```
g++ spacesim.cpp -o spacesim -lraylib
```
or just
```
make build
```
